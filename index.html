What this cannot establish

A high score does not prove motive, intent, coordination, wrongdoing, or causation. Missing alternatives or weak evidence can materially change the result.

METHODOLOGY

What NSENT is doing

NSENT is a structured hypothesis-comparison tool. Plain-language inputs become analytical dimensions used to compare explanations.

Support(H) = .28 Evidence + .16 Context + .13 Incentive + .13 Capability + .10 Constraints + .10 Timing + .10 Distribution

The static edition uses deterministic lexical matching so the calculation is inspectable. The extraction layer is isolated so a future model-backed analyzer can replace it without changing the interface.
